# ADR-0003: Use `RigWarden` for the provisional pre-alpha community repository

- Status: Accepted for GitHub pre-alpha only
- Date: 2026-08-08
- Owner: project owner
- Requirements: `QA-001`, `SEC-007`
- Supersedes: public-use portion of `ADR-0001`

## Context

The preliminary name screen rejected a superseded candidate due to materially
adjacent collisions. The project owner selected `RigWarden` as the new
public-facing identity. A quick exact-term screen did not identify a relevant
music/modeler/software collision, but it was not a comprehensive trademark,
domain, handle, package, or jurisdictional clearance.

## Decision

Use **RigWarden** as the display identity and `rigwarden` as the proposed
GitHub repository slug for this open-source pre-alpha repository. Public
materials must call the name *provisional* and must not imply legal clearance,
trademark ownership, store availability, package-ID availability, domain or
handle availability, product readiness, or hardware compatibility.

Historical planning and evidence remain preserved for traceability. They do not
constitute RigWarden public-brand approval or legal clearance.

## Consequences

### Allowed now

- Public source hosting under the RigWarden display name and `rigwarden` GitHub slug.
- Explicitly labeled pre-alpha concept images and source/research discussion.
- Community contributions that follow the repository policies.

### Still blocked

- Trademark, legal-clearance, or exclusivity claims.
- Store titles, package IDs, domains, social handles, paid product identity, or
  reservation/purchase actions.
- Claims that concept images are working UI, or that any modeler/device is supported.

## Follow-up gate

Before a beta, release, store submission, package publication, domain/handle
reservation, or trademark use, commission a current multi-jurisdictional
clearance and update the naming decision with its scope and owner.
