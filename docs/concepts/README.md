# RigWarden visual concept references

The PNGs in this directory are generated pre-alpha **concept references** for
future UI and asset direction. They are not runtime assets, source screenshots,
device captures, compatibility proof, or an implemented UI specification.

The locked layout vocabulary is: preset and scene rail at left, signal-flow
canvas in the center, inspector at right, and skin selector along the bottom.
Future implementation must still satisfy the project accessibility and strict
TDD contracts; a concept image does not waive either one.

Current skin directions:

- `rigwarden-studio-carbon-concept.png` — dark modern base.
- `rigwarden-stage-amber-concept.png` — warm, bold performance mode.
- `rigwarden-console-ivory-concept.png` — clean classic studio surface.
- `rigwarden-electric-slate-concept.png` — cool technical night mode.
