# Contributing

Thanks for helping. This project is in a private bootstrap phase and its public
identity is not yet cleared; do not create or reserve public names, packages,
domains, store listings, or handles on its behalf.

## Before proposing a change

- Read `AGENTS.md`, the applicable work item, and the strict-TDD skill.
- Keep the change within the packet's allowed paths.
- For production behavior, capture and run the focused failing test before the
  minimal implementation, then record the green result and required sweeps.
- Do not guess protocol bytes or add vendor/competitor artwork, layouts,
  binaries, captures, manuals, or unknown-rights fixtures.
- Preserve third-party notices and fixture provenance exactly.

## Reviews and security

Implementers do not approve their own work. Use the packet's independent review
role and keep verification labels honest. Report security issues privately as
described in `SECURITY.md`; do not open a public exploit report.
